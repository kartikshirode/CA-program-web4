Modal Dialog

A fully accessible modal dialog with focus trap, keyboard navigation, and ARIA compliance. Features backdrop clicking, ESC key closing, and proper focus management.

Accessibility Features: Focus trap keeps keyboard navigation within modal • ARIA roles and properties • ESC key closes modal • Focus returns to trigger element

Usage Example:

const modal = new Modal({
  backdrop: true,
  keyboard: true,
  focus: true
});

modal.setTitle('Example Modal')
     .setBody('<p>Modal content goes here</p>')
     .setFooter('<button class="btn btn-primary">Save</button>')
     .open();
  • Keyboard navigation with focus trap
  • ARIA roles and properties for screen readers
  • Customizable backdrop and keyboard behavior
  • Event callbacks for all modal states
  • Responsive design for mobile devices

Tabbed Content

Accessible tabs with keyboard navigation, ARIA attributes, and support for both horizontal and vertical orientations.

Accessibility Features: Arrow key navigation • ARIA tablist/tab/tabpanel roles • Proper focus management • Screen reader announcements

Component Overview

This tabs component provides a clean, accessible interface for organizing content into multiple sections. It supports keyboard navigation and follows WCAG guidelines.

  • Horizontal and vertical orientations
  • Keyboard navigation with arrow keys
  • Dynamic tab addition and removal
  • Customizable activation behavior

Accessibility Features

Built with accessibility as a core requirement:

  • Proper ARIA roles and states
  • Keyboard navigation support
  • Screen reader compatibility
  • Focus management
  • High contrast mode support

Customization Options

Flexible configuration options:

  • Orientation (horizontal/vertical)
  • Activation on focus or click
  • Content destruction on hide
  • Custom styling with CSS variables
  • Event callbacks for state changes
const tabs = new Tabs(element, {
  orientation: 'horizontal',
  activateOnFocus: false
});

// Add new tab dynamically
tabs.addTab('New Tab', '<p>Tab content</p>');

// Listen for tab changes
tabs.on('afterActivate', (data) => {
  console.log('Tab activated:', data.index);
});

Carousel/Slider

Responsive carousel with touch/swipe support, keyboard controls, and full accessibility features. Includes autoplay, infinite loop, and multiple transition effects.

Accessibility Features: Keyboard navigation with arrow keys • ARIA live regions for announcements • Pause autoplay on focus/hover • Descriptive slide labels
Slide 1 - Welcome
Slide 2 - Features
Slide 3 - Accessibility
Slide 4 - Responsive
Slide 5 - Touch Support
const carousel = new Carousel(element, {
  infinite: true,
  autoplay: true,
  autoplaySpeed: 3000,
  arrows: true,
  dots: true,
  swipe: true
});

// Navigation methods
carousel.nextSlide();
carousel.prevSlide();
carousel.goToSlide(2);

// Event handling
carousel.on('beforeChange', (data) => {
  console.log('Changing to slide:', data.nextSlide);
});
  • Touch and swipe gesture support
  • Keyboard navigation with arrow keys
  • Autoplay with pause on hover/focus
  • Infinite loop and fade transitions
  • Responsive breakpoint support
  • ARIA live regions for announcements
